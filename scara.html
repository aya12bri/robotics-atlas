SCARA robot (R-R-P-R)

← Robot list · Learn the basics

Tasks: fast pick-and-place, screwing, electronics assembly. It is stiff vertically and fast horizontally.

Kinematic diagram (schéma cinématique), top view

In the top view, q3 slides along the direction you are looking, so it is drawn as a square. The circles are the rotating joints.

Forward kinematics of a SCARA

x = L1·cos(q1) + L2·cos(q1+q2)
z = −( L1·sin(q1) + L2·sin(q1+q2) )
height = fixed height − q3
tool angle = q1 + q2 + q4

Compare with the arm page: the x and z position only depends on q1 and q2. The prismatic joint q3 only changes the height. That separation is why SCARAs are easy to program.
