Your first program: variables and types

20 min
You will learn

why robots are programmed in Python, how to install it, how to run a program, and the four basic types of values: whole numbers, decimal numbers, texts and true/false.

In one sentence

A program is a list of instructions run from top to bottom; a variable is a name that holds a value.

1.1 Why Python?

Python is the most used language to prototype robots: it is easy to read, it has ready-made libraries for maths (NumPy), plots (Matplotlib), vision (OpenCV) and robots (ROS 2 speaks Python). The fast loops inside a motor drive are written in C or C++, but almost everything around them — tests, calculations, planning, data — is written in Python.

1.2 Install and run

  1. Install Python 3 from python.org (on Windows, tick “Add Python to PATH”). On Linux and macOS it is often already there.
  2. Install an editor: Thonny (made for beginners) or VS Code with the Python extension.
  3. Write the program below in a file hello.py and run it (the Run button, or python hello.py in a terminal).
  4. Later, add the libraries of this course with pip install numpy matplotlib.

Computing with angles: the math module

20 min
You will learn

the operators, the math module, radians and degrees, and how to compute the end of a robot link with cos and sin, and an angle with atan2.

In one sentence

The functions of math work in radians: convert with math.radians before cos and sin, and back with math.degrees.

2.1 Operators

The remainder % is very useful for angles: a % 360 brings any angle back between 0 and 360°.

2.2 The end of a link

A link of length L turned by an angle θ ends at x = L cos θ, y = L sin θ (the maths course, lesson 1). In Python:

# where is the end of a link? the math module works in radians
import math

L = 0.5                        # link length (m)
theta_deg = 30                 # joint angle in degrees
theta = math.radians(theta_deg)

x = L * math.cos(theta)
y = L * math.sin(theta)
print(f"x = {x:.3f} m, y = {y:.3f} m")

# and back: the angle of a point with atan2 (right in every quadrant)
angle = math.degrees(math.atan2(y, x))
print(f"angle = {angle:.1f} deg")
x = 0.433 m, y = 0.250 m
angle = 30.0 deg
  • import math loads the module once, at the top of the file.
  • f"x = {x:.3f}" is an f-string: the value of x is written with 3 decimals.
  • math.atan2(y, x) gives the angle of a point in every quadrant; math.atan(y / x) gets it wrong when x is negative.
The most common bug in robot code

Passing degrees to math.cos: math.cos(90) is −0.448, not 0, because 90 is read as 90 radians. Always convert: math.cos(math.radians(90)) ≈ 0.

3.2 The loop of every robot

Every robot runs the same loop, many times per second: read the sensors, compute what to do, command the motors, wait for the next period. In Python it is a while loop; on a microcontroller it is the loop() function of the electronics course.

Indentation

Use 4 spaces for each level. A line that is not indented any more is after the block, not inside it. A missing or extra space gives an IndentationError or, worse, a program that does something else.

Functions: the forward kinematics of an arm

25 min
You will learn

how to write a function with def, give it parameters and default values, return several results, and turn the forward kinematics of a 2-link arm into one reusable line.

In one sentence

A function packs a calculation under a name: you write it once, test it once, and call it everywhere.

4.1 The forward kinematics as a function

x = L1 cos θ1 + L2 cos(θ1 + θ2)   y = L1 sin θ1 + L2 sin(θ1 + θ2)

# a function for the forward kinematics of a 2-link arm
import math

def fk(theta1, theta2, L1=0.5, L2=0.4):
    """Angles in degrees -> position (x, y) of the tool in metres."""
    t1 = math.radians(theta1)
    t12 = math.radians(theta1 + theta2)
    x = L1 * math.cos(t1) + L2 * math.cos(t12)
    y = L1 * math.sin(t1) + L2 * math.sin(t12)
    return x, y

x, y = fk(30, 45)
print(f"tool at ({x:.3f}, {y:.3f}) m")
print(fk(0, 0))            # arm stretched along x: (0.9, 0.0)
tool at (0.537, 0.636) m
(0.9, 0.0)
  • def fk(theta1, theta2, L1=0.5, L2=0.4): — two required parameters and two with a default value.
  • The text between triple quotes is the docstring: it says what goes in and what comes out, with the units.
  • return x, y returns two values; x, y = fk(30, 45) takes them apart.
Always test a function with a pose you know

With all the angles at 0 the arm is stretched along x: fk(0, 0) must give (0.9, 0). With θ₁ = 90°, θ₂ = 0 it points up: (0, 0.9). Two lines of test catch most mistakes (degrees forgotten, sin and cos swapped).

Key terms

  • function, def
  • parameter, default value
  • return
  • docstring

NumPy: vectors, matrices, whole trajectories

30 min
You will learn

how NumPy stores vectors and matrices, the matrix product @, a rotation matrix as a function, and how to compute a whole trajectory in one line instead of a loop.

In one sentence

NumPy turns the maths of the course into code almost word for word: a vector is np.array, a product of matrices is @.

6.1 A rotation in code

R(θ) = [[cos θ, −sin θ], [sin θ, cos θ]]   a′ = R(θ) a

# NumPy: vectors, matrices and a whole trajectory at once
import numpy as np

a = np.array([0.3, 0.4])
print("length of a:", np.linalg.norm(a))          # 0.5

def rot(deg):
    t = np.radians(deg)
    return np.array([[np.cos(t), -np.sin(t)],
                     [np.sin(t),  np.cos(t)]])

print("a turned by 90 deg:", rot(90) @ a)          # @ = matrix product

t = np.linspace(0, 2, 5)                           # 5 instants from 0 to 2 s
theta = 90 * t / 2                                 # a joint going from 0 to 90 deg
print("t     =", t)
print("theta =", theta)

6.2 No loop needed

theta = 90 * t / 2 computes the 5 angles at once, because t is an array: every operation is done on every element. This is shorter and about 100 times faster than a for loop on long trajectories.

* is not @

A * B multiplies element by element; the matrix product of the maths course is A @ B. Mixing them up gives a result of the right size but wrong values.

7.1 Plot a joint trajectory

# plot a joint trajectory and read sensor data from a file
import numpy as np

8

Classes and a first controller

30 min
You will learn

how a class groups the data of a robot and its functions, what self and __init__ are, and how to write the loop of a proportional controller that brings a joint to a target.

In one sentence

A class is a mould for objects: Arm2() makes a robot that keeps its own lengths and angles and knows how to compute its tool.

8.1 The class Arm2

  • __init__ runs when the object is made: it stores L1, L2 and the angles q in self.
  • self is “this robot”: two objects Arm2() have their own angles.
  • tool() is a method: a function that uses the data of the object (the forward kinematics of lesson 4).

8.2 A proportional controller

e = qtarget − q   ω = Kp e   q ← q + ω Δt

# a small robot class and a proportional controller on one joint
import math

class Arm2:
    def __init__(self, L1=0.5, L2=0.4):
        self.L1, self.L2 = L1, L2
        self.q = [0.0, 0.0]                      # joint angles in degrees

    def tool(self):
        t1, t12 = math.radians(self.q[0]), math.radians(self.q[0] + self.q[1])
        return (self.L1 * math.cos(t1) + self.L2 * math.cos(t12),
                self.L1 * math.sin(t1) + self.L2 * math.sin(t12))

arm = Arm2()
target, Kp, dt = 60.0, 4.0, 0.05                 # P controller on joint 1
for k in range(6):
    error = target - arm.q[0]
    speed = Kp * error                           # deg/s
    arm.q[0] += speed * dt
    print(f"step {k}: q1 = {arm.q[0]:5.1f} deg, error = {error:5.1f}")
print("tool at (%.2f, %.2f) m" % arm.tool())
step 0: q1 =  12.0 deg, error =  60.0
step 1: q1 =  21.6 deg, error =  48.0
step 2: q1 =  29.3 deg, error =  38.4
step 3: q1 =  35.4 deg, error =  30.7
step 4: q1 =  40.3 deg, error =  24.6
step 5: q1 =  44.3 deg, error =  19.7

At each step the error is multiplied by 1 − KpΔt = 1 − 4 × 0.05 = 0.8: 60 → 48 → 38.4 → … The joint gets closer and closer without overshoot. A larger Kp is faster, but if KpΔt > 2 the error changes sign and grows at every step: the loop is unstable.

Where to go next
